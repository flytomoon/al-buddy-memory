Al Buddy for Claude Code

Never lose your work with Claude.

All your work with Claude is never lost — you have it forever, and you can bring it anywhere. That's the whole point.

Decisions, preferences and what you learned together carry over from one session to the next, in one file on your own machine.

> /plugin install al-buddy@al-buddy

How it works

Three steps. The first is the only one you have to do.

1

Install the plugin

Two commands in Claude Code. Nothing to configure, no account, no key. The first start downloads the memory server and a small search model, once.

2

Work the way you do now

Claude remembers decisions, preferences and facts about your projects as you go, and looks them up before answering about past work. Every session starts with a short briefing of what matters.

3

Keep it. Take it anywhere.

It is one file on your computer. Nothing is overwritten: what stops being true is retired and kept, with a date. Export it all to one documented JSON file, or use the same memory in Codex and the ChatGPT desktop app.

The commands

You never have to type them — Claude recalls and remembers on its own. They are there for when you want to be explicit.

/al-buddy:recall <question>Search your memory and answer from it, saying where each answer came from and since when.
/al-buddy:remember <fact>Store a fact in your own words. Passwords and keys are refused.
/al-buddy:forget <fact>Retire a fact that is no longer true. It stops coming back, and stays in history with the date and reason.
/al-buddy:statusHow much is remembered, where the file is, when it last changed, and whether semantic search is on.
/al-buddy:export [file]Save everything to one JSON file you own — a backup, or a move to another machine or assistant.
/al-buddy:import <file>Restore from an export. It checks the whole file first and is safe to run twice.
/al-buddy:helpOne screen: what it is, the commands, where your data lives, and how to delete it.

Take it anywhere

Export everything to one file and restore it on a new laptop. Or export a readable copy — the retired fact is still there, struck through, with the dates it was true.

Export, then import elsewhere
$ al-buddy-memory export --out ~/al-buddy-memory-backup-2026-10-03.json
exported ~/.al-buddy-memory/brain.db to ~/al-buddy-memory-backup-2026-10-03.json (7937 bytes, portable)

$ AL_BUDDY_MEMORY_DB=~/new-laptop/brain.db al-buddy-memory import ~/al-buddy-memory-backup-2026-10-03.json

Our privacy promise

Your memory is yours. Here is everything that happens to it.

  • It stays on your computer. One file, ~/.al-buddy-memory/brain.db. We never see it.
  • Nothing is sent anywhere. No account, no telemetry, no analytics, no crash reports.
  • Two downloads, once each: the software from npm, and the search model (about 90 MB) from Hugging Face. Then it runs offline.
  • Secrets stay out. Anything that reads like a password, key or token is kept out of every assistant's recall.
  • One honest caveat: what Claude recalls becomes part of your conversation with Claude, which Anthropic handles like anything else you type.
  • Deleting is one step: remove the ~/.al-buddy-memory folder. Export first if you want a copy.

The full statement: PRIVACY.md. The code is open source (Apache-2.0); you can read every line.

Install

You need Node.js 22 or later (node --version). The first start downloads about 500 MB of software and a 90 MB search model, once.

Claude Code

The plugin

In Claude Code:

/plugin marketplace add flytomoon/al-buddy-memory
/plugin install al-buddy@al-buddy

Start a new session, then try /al-buddy:help. Full guide.

Codex · ChatGPT desktop

The same memory

They share one setup. From a shell:

codex mcp add al-buddy-memory -- npx -y al-buddy-memory mcp

Or in the ChatGPT desktop app: Settings → MCP servers → Add server, choose STDIO, command npx -y al-buddy-memory mcp, save, Restart.

Or by hand

~/.codex/config.toml

[mcp_servers.al-buddy-memory]
command = "npx"
args = ["-y", "al-buddy-memory", "mcp"]
startup_timeout_sec = 120

The longer timeout covers the first download. Claude Code and Codex then share one memory file, and each fact records which one wrote it.

Questions

Does it send my memory anywhere?

No. The memory is a file on your machine and the software never uploads it. The only network use is two one-time downloads: the software from npm and the search model from Hugging Face. What Claude recalls does become part of your conversation with Claude, like anything you type.

What does it cost?

Nothing. It is open source (Apache-2.0), needs no account or API key, and runs on your own computer.

Will it fill up Claude's context?

No. The session-start briefing is at most 2,000 characters, and everything else is looked up only when it is needed.

What happens when something stops being true?

It is retired, not deleted: it stops coming back in recall and stays in history with the date it ended, the reason, and what replaced it. So "where was staging last month?" still has an answer.

How do I take it to another computer or assistant?

/al-buddy:export writes one JSON file in a documented format; /al-buddy:import restores it on the other machine. Codex and the ChatGPT desktop app can use the same memory directly (see Install).

How do I delete it?

Remove the ~/.al-buddy-memory folder. That is all of it. Uninstalling the plugin leaves your memory in place, so a reinstall picks up where you left off.

I'm on an Intel Mac.

It works, with search by keyword only: the on-device model runtime has no build for Intel Macs. /al-buddy:status tells you which mode you are in.

The memory tools don't appear after installing.

The very first start downloads the software and can outlast the connection timeout. Wait a minute and run /reload-plugins. Check node --version is 22 or later. More troubleshooting.
