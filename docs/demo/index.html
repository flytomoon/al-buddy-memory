What the library underneath does differently

  • Nothing is ever deleted. A fact that stops being true gets a validTo and stays, with what replaced it. Ask what was true last March.
  • Every fact says who asserted it — user, AI-inferred, guardian, system — and every relation carries provenance too.
  • Raw text is the source of truth. Embeddings are a disposable cache tagged with the model that made them. Switch models, lose nothing.
  • It leaves the vendor intact. One documented export format with a schema and a proven lossless round-trip. No service, no key, no account.
  • Governance is enforced, not implied. Policies in front of every write, read and export, with an append-only audit trail.

Give your agent facts it can weigh — the MCP server returns provenance and validity with every recall:
